# Trivia App Backend

# 🎯 Trivia App

A scalable and secure backend-powered Trivia Application built using **Java Spring Boot**.  
The project is designed to provide category-based quizzes where users can register, authenticate securely, attempt quizzes, and track their scores.

This project focuses on building a real-world backend architecture using modern Java technologies, REST APIs, authentication mechanisms, database integration, and scalable software development practices.

---

# 🚀 Current Features

## ✅ User Management
- User registration and login system
- Secure authentication setup
- Role-based backend architecture preparation

## ✅ Quiz Management
- Category-based quiz structure
- Question management APIs

- Score tracking functionality

## ✅ REST APIs
- RESTful backend APIs using Spring Boot
- Structured controller-service-repository architecture

## ✅ Database Integration
- Persistent storage using relational databases

# 📂 Project Architecture

The project follows a layered backend architecture:


Controller Layer  → Handles APIs
Service Layer     → Business Logic
Repository Layer  → Database Operations
Model Layer       → Entity Definitions


This architecture improves:

* Code organization
* Scalability
* Maintainability
* Testing capabilities
